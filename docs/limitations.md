# Limitations

Four PRs from two Python libraries cannot establish general trends. Here, review-approval group and repository coincide; the comparison is strongly confounded. Most origin classifications are unknown. Verified routine dependency automation is not an AI coding-agent cohort.

File overlap does not attribute changes to lines introduced by the earlier PR. Keywords can describe docs or ordinary upgrades. Rename tracking, deleted-file follow-up, blame-based attribution, contributor-experience controls and independently human-coded validation are not implemented. Committer time is an imperfect proxy for default-branch integration time.

Future source changes, rewritten branch histories, incomplete reviews, inaccessible metadata and API limits affect reproducibility. Exact derived snapshot analysis is offline reproducible; collection depends on current public APIs. Full pagination at a configured limit is marked incomplete. Tiny-sample Wilson intervals describe binomial uncertainty only; they do not correct selection bias or repository clustering.

No public live dashboard deployment, peer review, paper replication, causal relationship, AI superiority/inferiority, or confirmed vulnerability is claimed by this implementation.
